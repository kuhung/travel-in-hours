## 6. 用户 Review 已确认的配色修正补充说明

根据用户 Review 反馈，已在交付基线上补齐最后配色修正与根因闭环：
1. **导出红大圈覆盖内圈的根因**：活动地图按 properties.value 降序，但导出离屏绘制未做排序。通过生产纯函数 `sortIsochronesForRender`，活动地图与导出严格统一为大圈先画、小圈后画，有效解决后画大圈遮盖内圈问题；
2. **三档色值与透明度**：
   - 15分钟：青绿（边框/墨水 `#0f766e`，面填充 `#2dd4bf`，opacity `0.32`）
   - 30分钟：蓝（边框/墨水 `#1d4ed8`，面填充 `#60a5fa`，opacity `0.23`）
   - 60分钟：靛蓝（边框/墨水 `#4338ca`，面填充 `#818cf8`，opacity `0.16`）
3. **标记对比度与 Alpha 合成证据**：
   - 白字与深底对比度：15m (5.47:1)、30m (6.70:1)、60m (7.90:1)、目的地 (5.47:1) 均满足 WCAG AA (>= 4.5:1)；
   - Alpha 合成数学证明：证明先画 60m 后画 15m 时，15m 置顶信号贡献完整保持 32%；反之若后画 60m 会将 15m 信号压制至 20.7% 并产生外圈色彩涂染；
4. **未重新目视核验边界声明**：自动化测试已全面证明生产排序与合成数值正确；用户仅确认了方案原则与色值方向并授权关单，真实高分屏浏览器中 Canvas 导出的图像整体排版与美观度未在无浏览器环境下目视核验，留待用户手动验收。
