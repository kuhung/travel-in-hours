1. 执行 `npm run dev`，打开浏览器无痕窗口访问 `http://localhost:3000`；
2. 页面仅展示引导弹层，网络面板无主动发起的探索分析或定位请求（热门地标缓存预加载除外）；
3. 点击“先看上海示例”，等时圈与地点清单正常呈现；
4. 右上角工具栏完整显示“宜山路地铁站”、“驾车”、“15/30/60m”、“示例”黄色标签；起点全名无 4 字符截断；

5. 地图与清单仍展示旧宜山路驾车结果，绝不因表单草稿改动而丢失；点击“恢复原条件”，表单即刻复原。

### 路径 4：收录边界诚实空态核验
1. 点击“修改”打开面板，在出发地点中选择收录区域外的真实预设地标（如“杭州 - 杭州东站”），点击“查看可达范围”；
2. 等时圈计算完成后，清单面板依然存在（不留白），展示“超出当前收录范围”；
3. 面板诚实说明目前仅精选收录上海地点，提示“这并不代表附近没有现实生活设施”，并提供“先看上海示例”与“修改出发点”按钮；点击“先看上海示例”顺畅切回上海。

### 路径 5：移动端 48vh 折叠与地点选中核验
1. 切换浏览器控制台为移动端尺寸（如 iPhone 14，390px 宽）；
2. 观察底部 48vh 清单面板，点击顶部明确的“收起清单”操作按钮；
3. 清单平滑收起，底部展示浮动药丸“查看地点清单”；
4. 在地图上自由缩放、拖拽平移，确认地图视野不被反复强行重置；
5. 点击浮动药丸展开清单，点击清单中任一地点，卡片高亮呈激活状态，底部信息栏显示所选地点名称与描述（无内部工程占位文字），地图对应标记同步高亮。
