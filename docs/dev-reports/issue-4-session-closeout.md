## 2. 已实现能力与可用入口

在已收口的 #5–#10 范围内，系统已建立如下功能与架构出口：

### 2.1 状态与探索生命周期 (#5, #7, #8)
- **草稿与结果严格隔离**：用户在编辑面板中的城市、地标或出行方式变更仅影响草稿条件，未点击“更新结果”前不污染已有已提交（committed）结果；
- **显式地图选点保护**：仅在显式点击“在地图上选点”后才进入选点交互，常规地图拖拽与点击不清空探索结果；
- **并发请求生命周期控制**：异步请求携带唯一身份，慢请求晚返回自动废弃，防止覆盖最新探索；
- **配额与估算披露**：保留每日 5 次自定义选点限额策略，如实披露 500m 网格对齐实估与非实时路况承诺。

### 2.2 地点数据与几何判定 (#6, #8)
- **坐标系统统一**：计算层统一在 WGS-84 坐标空间进行点与等时圈多边形包含判定，输出给 Leaflet 渲染层时单向转换为 GCJ-02；
- **最小圈层互斥归属**：一个地点若处于多个圈层内，严格归入其最小可达圈层（如 15 分钟），保证层级互斥与编号单调递增；
- **覆盖状态诚实呈现**：独立区分“有匹配（matched）”、“已收录范围内无地点（covered-empty）”、“未收录范围（uncovered）”与“部分超出（partial）”，不以空白列表暗示“没有地点”。

### 2.3 目的地行动与官方导航 (#9)
- **双向联动与详情承载**：地图标记与左侧清单支持点击和键盘回车双向点选，统一激活 `selectedPOIId`，在左侧抽屉或浮层展开 `POIDetailCard`；
- **高德开放平台官方直达**：采用高德官方 URI 路径规划接口，经火星坐标单次转换后直达起终点官方导航；
- **平台能力感知与骑行限制**：针对高德开放平台网页端不支持骑行导航的真实限制，在桌面端如实提示并提供“复制手机导航信息”回退，不静默改驾车。

### 2.4 分享信息架构与离屏导出 (#10)
- **解耦格式与平台**：第一级分享入口仅保留“复制交互链接”与“生成分享图片”，清理废弃的微信二级嵌套 Tab 与重复菜单组件；
- **明确分享对象**：支持“所选地点卡”与“整次探索卡”两种明确对象，在弹窗内无缝切换，地点卡突出起点与目的地预估时间；
- **离屏独立渲染**：引入独立的 960x600 离屏 Leaflet 容器与 `initTileLoadTracker` 控制器，瓦片完全加载后再行绘制，全程不调用 `window.__leaflet_map.setView`，避免干扰用户当前活动的探索视野；
- **确定性保存**：废除向图片剪贴板写入的不可靠逻辑，生成产物明确触发 PNG 文件下载，并保留已有 Blob 支持多次重复保存免计算。

### 2.5 最终配色修正与排序闭环 (#10 收尾)
- **大圈覆盖内圈根因修复**：导出离屏渲染接入生产排序纯函数 `sortIsochronesForRender`，不论 API 输入顺序如何，固定按 `properties.value` 从大到小降序绘制（60m -> 30m -> 15m），大圈先画底图、小圈后画顶层，有效解决后画大圈遮盖内圈问题；
- **统一三档克制配色（Refactoring UI 体系）**：
  - 15分钟：青绿 `#0f766e`（Teal-700），填充 `#2dd4bf`，透明度 `0.32`（小圈清晰）；
  - 30分钟：蓝 `#1d4ed8`（Blue-700），填充 `#60a5fa`，透明度 `0.23`（中圈均衡）；
  - 60分钟：靛蓝 `#4338ca`（Indigo-700），填充 `#818cf8`，透明度 `0.16`（大圈极淡透明度保留道路底图）；
- **目的地标记解耦**：目的地标记统一采用深青色 `DESTINATION_STYLE.ink`（#0f766e）配白色加粗描边与 1.15 倍放大，告别危险/错误红混淆；真正错误态（如重试按钮）保留红色；
- **单一事实源收敛**：清理所有硬编码 `LAYER_COLORS`，全站地图、导出图例、页面图例、清单与标记统一引用 `src/data/isochrone-config.ts`。
